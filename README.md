## 🟢 GREEN ZONE — Xbox fan arcade

A complete, asset-free browser survival shooter inspired by Xbox. Hold the
arena, chain kills for a score multiplier, and let your shields recharge
between fights. Every fifth wave sends a Sentinel boss.

**Play locally**

```bash
python3 -m http.server 3002
# open http://localhost:3002
```

**Controls**

| Action | Keyboard / mouse | Gamepad | Touch |
| --- | --- | --- | --- |
| Move | `WASD` / arrows | Left stick | Left half of screen |
| Aim | Mouse (auto-fire) | Right stick | Right half of screen |
| Dash | `Space` / `Shift` | `A` | DASH button |
| Pause | `Esc` / `P` | `Start` | Pause button |

- No build step and no dependencies: plain HTML, CSS, and canvas 2D.
- Sound is synthesised with WebAudio — no audio files.
- Scores persist in `localStorage`.
- Responsive layout with safe-area handling for phones and tablets.
- Unofficial fan project. Not affiliated with Microsoft. Xbox is a trademark
  of Microsoft Corporation.
